# Laporan Praktikum Pertemuan 1 - HTML Dasar & Markdown

## Ringkasan Laporan Praktikum HTML Dasar
Pada praktikum Pertemuan 1 ini, saya mempelajari struktur dasar dokumen HTML5 serta penggunaan sintaks Markdown untuk dokumentasi proyek. Pada latihan utama, saya membuat halaman "Biodata Pribadi" yang tersusun secara semantik dengan memanfaatkan hierarki elemen heading `<h1>` hingga `<h3>`.

Dalam penyusunan konten, digunakan beberapa format penekanan teks seperti tag `<strong>` untuk memperjelas identitas diri, `<em>` untuk istilah asing, serta `<br>` untuk pemisah baris pada detail semester dan domisili tanpa membuat paragraf baru.

### Masalah dan Solusi
* **Masalah:** Karakter khusus seperti `<` dan `>` pada penulisan contoh tag dapat berisiko dibaca oleh browser sebagai sintaks HTML yang salah. Selain itu, simbol ampersand (`&`) juga memerlukan penulisan yang aman secara standar markup.
* **Solusi:** Menerapkan *HTML Entities*, yaitu `&lt;` untuk `<`, `&gt;` untuk `>`, `&amp;` untuk `&`, serta `&copy;` untuk menampilkan simbol hak cipta (©).

Secara keseluruhan, dokumen HTML dan Markdown ini dapat dirender dengan baik, rapi, dan terstruktur pada perangkat desktop maupun seluler.
